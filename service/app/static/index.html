How it works

One YAML config drives every stage, so each experiment is reproducible end to end.

Fine-tuneDistilBERT and T5-small with the HF Trainer, tuned with Optuna.
QuantizePyTorch dynamic INT8 and ONNX Runtime uint8.
EvaluateAccuracy, macro-F1 and ROUGE, all variants on one code path.
Benchmarkp50 and p95 CPU latency, throughput and size, with fixed threads.
ServeVersioned registry, production aliases, FastAPI with a model cache.
